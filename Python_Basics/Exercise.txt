# Top 10 Tasks to Do After Learning Python

Congratulations on learning the basics of Python! 🎉
The next step is to **apply your knowledge to real-world tasks and projects**.
Below is a list of **10 practical tasks** that will help you strengthen your Python skills.

---

## 📌 1. Build a Command Line To-Do List

Create a simple CLI application that allows users to:

* Add tasks
* View tasks
* Delete tasks
* Mark tasks as completed

**Skills Used:** Lists, file handling, loops, functions.

---

## 📌 2. Create a Password Generator

Build a program that generates strong random passwords.

Features:

* User chooses password length
* Include numbers and symbols
* Generate secure random password

**Libraries:** `random`, `string`

---

## 📌 3. Develop a Simple Calculator

Create a calculator that performs:

* Addition
* Subtraction
* Multiplication
* Division

Bonus:

* Add a **loop-based menu system**

---

## 📌 4. Build a Number Guessing Game

The computer generates a random number and the user tries to guess it.

Features:

* Hint if the guess is too high or too low
* Limit the number of attempts
* Display final score

---

## 📌 5. Create a File Organizer

Write a script that organizes files into folders automatically.

Example:

```
Downloads/
   Images/
   Documents/
   Videos/
```

**Skills Used:** `os`, `shutil`

---

## 📌 6. Build a Web Scraper

Create a script that extracts information from a website.

Example:

* News headlines
* Product prices
* Article titles

**Libraries:** `requests`, `BeautifulSoup`

---

## 📌 7. Create a Simple API Project

Use a public API to fetch data.

Example APIs:

* Weather API
* Crypto price API
* Movie database API

Display results in the terminal.

---

## 📌 8. Build a GUI App

Create a graphical application using:

* `Tkinter`
* or `PyQt`

Example projects:

* Calculator
* Notes app
* Unit converter

---

## 📌 9. Automate a Daily Task

Use Python to automate repetitive tasks.

Examples:

* Rename multiple files
* Send automated emails
* Download reports automatically

**Libraries:** `smtplib`, `schedule`, `os`

---

## 📌 10. Build a Mini Data Analysis Project

Analyze a dataset and visualize results.

Steps:

* Load data
* Clean data
* Analyze patterns
* Create charts

**Libraries:**

* `pandas`
* `matplotlib`
* `seaborn`

---
